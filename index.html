Le projet

Le tableau de bord, en mode CarPlay

OpenPad reprend le tableau de bord de VESC Dashboard — les compteurs, la carte GPS et les modes — et l'installe dans un écran d'accueil type iPad / CarPlay, avec un dock, des applis et un vrai mode sombre.

Les compteurs VESC sont ceux du Dashboard : mêmes jauges, mêmes styles, même source. OpenPad ajoute l'interface autour : écran d'accueil, dock, applications (Messages, Musique, Calendrier, Météo, Téléphone…), mode sombre et installation PWA.

Comme le Dashboard, OpenPad est une page HTML/CSS/JS unique, gratuite et installable. Sur Android, installez la PWA depuis Chrome ; sur iPad/iPhone, ajoutez-la à l'écran d'accueil depuis Safari (ou utilisez Bluefy pour le Bluetooth).

EN RÉSUMÉ

  • Compteurs VESC identiques à VESC Dashboard
  • Interface iPad / CarPlay : accueil, dock, applis
  • 7 styles de compteur : Classique, VARG, Halo, Flux, Race, Moto, Analog
  • Cartographie OpenStreetMap et recentrage GPS
  • Mode sombre sur toutes les applications
  • Gratuit et open source — HTML/CSS/JS uniquement
Fonctionnalités

Tout le Dashboard, plus l'interface

Compteur VESC

Les compteurs du Dashboard : vitesse, batterie, tension, puissance, accélération et modes — mêmes rendus, mêmes styles.

Carte & GPS

Carte OpenStreetMap, position en temps réel, recherche de destination, itinéraire et bouton de recentrage.

Interface iPad / CarPlay

Écran d'accueil, dock, applis et transitions : le Dashboard devient un vrai pad, pas juste une page de compteur.

Mode sombre

Messages, Calendrier, Musique et le reste passent en sombre quand le thème sombre est actif.

Installation hors ligne

PWA installable : l'app se lance depuis l'écran d'accueil et garde ses fonctions essentielles sans réseau.

Android, iPad & iPhone

PWA sur Android (Chrome) et sur iPad/iPhone (Safari). Bluefy apporte le Bluetooth web si besoin.

Choisissez votre plateforme

Deux façons d'installer OpenPad — suivez les étapes de votre appareil.

Android APPLICATION

  1. Ouvrez l'app dans Chrome
  2. Touchez ⋮ puis « Installer l'application »
  3. Confirmez Installer : l'app arrive sur votre écran d'accueil et fonctionne même hors ligne
Installer sur Android →

iPad / iPhone SAFARI

  1. Ouvrez l'app dans Safari
  2. Touchez Partager puis « Sur l'écran d'accueil »
  3. Lancez OpenPad en plein écran depuis l'icône, comme une vraie app
